A complete analysis of what this software is, how it works, and what every part does.

Python 3.12+ CustomTkinter 6.0 SQLite (local) Matplotlib tkcalendar Desktop App Windows / macOS / Linux 1 280 × 720 min window

StudyFlow is a fully local, offline-first academic management desktop app for college students. It replaces a scattered combination of notes apps, spreadsheets, reminder apps, and timetable planners with a single all-in-one workspace — like a personal Notion, but purpose-built for a student's semester. All data lives in a single SQLite file (UserData/studyflow.db). No internet, no account, no cloud.

Architecture Overview

main.py
StudyFlowApp → Sidebar
navigation + Header
clock / search → navigate_to(page_id) → Module Frame
swapped in content_area → database/queries.py
SQLite CRUD

Navigation is page-swap: navigate_to() destroys the current frame and mounts a fresh one. No router, no state management library — each frame bootstraps itself by reading the DB on mount. The Sidebar and Header persist across all pages.

Key Data Flows

Study Streak

Dashboard loads → Check notes/attendance/assignments updated today → Read streak from settings (JSON) → Increment if gap = 1 day → Persist back to settings

Attendance %

User clicks +Present / +Absent → update_attendance(subject_id, …) → calculate_attendance_percentage() → attendance_color(pct) → green/amber/red

File Upload

User picks file (filedialog) → file_manager.save_file() copies to UserData/Files/{subject_id}/ → add_subject_file() records path in DB

Note Auto-Save

KeyRelease in editor → Cancel previous after() job → Schedule _save_note() 2 s later → update_note(id, title, content)

Theme / Design System (utils/theme.py)

All colours are (light_hex, dark_hex) tuples passed directly to CustomTkinter widgets. When ctk.set_appearance_mode("dark") is called, every widget re-renders automatically — no manual refresh.
